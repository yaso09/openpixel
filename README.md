# OpenPixel

OpenPixel is a toolkit for creating and rendering pixel art images and animations. It includes a TypeScript SVG renderer and a Rust CLI; a compatible Rust MCP server is planned.

## Project status

The v1 JSON format, TypeScript renderer, and Rust CLI are in place. See the [roadmap](docs/ROADMAP.md), [phase reports](docs/phases/), [renderer package](packages/pixelart/README.md), and [CLI guide](apps/cli/README.md).
