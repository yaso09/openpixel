# OpenPixel

OpenPixel is a toolkit for creating and rendering pixel art images and animations. Its planned components are a TypeScript SVG renderer, plus Rust CLI and MCP tools that create and manipulate compatible JSON assets.

> Early development: interfaces and file formats are still being designed.
